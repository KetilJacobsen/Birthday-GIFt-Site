A fun little webpage that celebrates someone's birthday with hover-to-reveal GIFs, bright colors, and playful fonts.

Features
Birthday header with photo, age, and date
Gift boxes that change to GIFs when hovered
Gradient background + Google Fonts
Simple, clean layout using Flexbox

Built With
HTML
CSS
Google Fonts

How to Use
Just open index.html in your browser. Make sure all images/GIFs are inside the images folder.
